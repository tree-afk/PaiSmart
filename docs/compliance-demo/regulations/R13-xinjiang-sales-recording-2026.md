# 新疆金融监管局关于进一步加强人身保险销售行为可回溯管理的通知

新金监规〔2026〕1号
各金融监管分局，米东、五家渠金融监管支局，各人身保险公司省级分公司，各保险专业中介机构、保险兼业代理机构，新疆保险行业协会:
为进一步规范新疆辖区人身保险销售行为，从源头上治理销售误导，切实保护各族消费者合法权益，推进群众身边不正之风和腐败问题集中整治向实处发力、向深处挺进，我局决定在《中国保监会关于印发〈保险销售行为可回溯管理暂行办法〉的通知》（保监发〔2017〕54号，以下简称《办法》）、《中国保监会关于落实〈保险销售行为可回溯管理暂行办法〉有关事项的通知》（保监消保〔2017〕265号，以下简称《通知》）基础上，结合《金融机构产品适当性管理办法》等规定，对深入推进人身保险销售行为可回溯管理工作提出以下要求：
一、实施销售行为可回溯管理的主体
在新疆辖内销售人身保险产品的保险公司、保险专业中介机构、保险兼业代理机构（以下统称保险机构），均应按照本通知规定对相关保险销售行为实施可回溯管理。
二、实施销售行为可回溯管理的产品
（一）除电话销售、互联网保险和通过自助终端投保的业务外，保险机构向自然人销售保险期间超过一年的人身保险产品（含保险期间不超过一年但保证续保的人身保险产品），应在取得投保人同意后，对销售过程关键环节以现场同步录音录像（以下简称“双录”）的可回溯手段予以记录，确保投保流程合规且投保人充分理解相关权益。
团体保险、专属商业养老保险、个人税收优惠型健康保险、政策性人身保险，以及通过个人养老金资金账户线上购买的商业养老保险等保险产品除外。
（二）保险机构开展电话销售、互联网保险及通过自助终端投保的业务，按照《中国保监会关于印发〈人身保险电话销售业务管理办法〉的通知》（保监发〔2013〕40号）、《中国银保监会关于规范互联网保险销售行为可回溯管理的通知》（银保监发〔2020〕26号），以及《国家金融监督管理总局关于印发〈商业银行代理销售业务管理办法〉的通知》（金规〔2025〕6号）的有关规定开展可回溯管理。
三、实施销售行为可回溯管理的主要内容
保险机构销售本通知规定的人身保险产品时，实施销售现场“双录”，录制内容至少包含以下销售过程关键环节：
（一）保险销售从业人员出示有效身份证明。
（二）保险销售从业人员出示投保提示书、产品条款和免除保险人责任条款的书面说明。
（三）保险销售从业人员向投保人履行明确说明义务，根据产品特征，告知投保人以下内容：所购买的产品为保险产品，以及承保保险机构名称、产品名称、保险责任、保险期限、缴费期限、缴费方式、缴费金额、赔偿限额、索赔程序、保单现金价值、续保条件、减轻或者免除保险人责任的条款；保单利益的不确定性、可能导致保费损失或者保单利益不及预期的事项；犹豫期及投保人在犹豫期内的权利；退保可能遭受的损失；需要投保人支付的保费总额、保单初始费用、保单管理费等各项费用，以及适当性匹配意见。
销售健康保险产品，应说明保险合同观察期的起算时间及对投保人权益的影响、合同指定医疗机构、续保条件和医疗费用补偿原则等。
（四）投保人对保险销售从业人员的说明告知内容作出明确肯定答复。
（五）投保人签署投保单、投保提示书、免除保险人责任条款的书面说明、投保声明（如有单独的签署文件）等相关文件。
（六）关系消费者利益的其他事项。
对于老年人、残障人士、国家通用语言能力受限人士等特殊群体，应通过更合适的方式开展可回溯管理，充分保障特殊人群知情权。
四、实施销售行为可回溯管理的内控要求
（一）保险机构要高度重视，完善内部销售行为可回溯管理制度，健全业务系统功能，强化宣导和培训，并采取有效措施确保客户信息的安全性，防止客户信息泄露，确保销售行为可回溯管理工作顺利实施。
（二）保险专业中介机构、非银行类保险兼业代理机构应在录音录像完成后将录制的视听资料和其他业务档案一并反馈至承保保险公司。银行类保险兼业代理机构应在录音录像完成后将新单业务录制成功的信息和其他业务档案一并反馈至承保保险公司。
（三）保险公司应建立保险销售录音录像资料质检制度，配备与销售人员岗位分离的质检人员，每月质检抽样比例不得低于当月承保的应录音录像保单件数的30%，针对投保人为特殊人群的录音录像保单，每月质检覆盖率不得低于60%，质检应在犹豫期内完成，其中销售投资连接保险产品或60周岁（含）以上投保人的“双录”视听资料应实现100%质检。质检发现视听资料不符合本通知要求的，应当自发现问题之日起15个工作日内整改。
（四）银行类保险兼业代理机构自存视听资料且未向保险公司提供视听资料的，应依照上述要求建立视听资料质检体系，自行开展质检，并在质检完成后的10个工作日内，将全部质检结果书面反馈至合作的保险公司。对于保险机构在自身质检中发现并反馈的银行“双录”违规问题，银行应即时响应并提供相关佐证材料，不得拖延、隐瞒或拒绝提供。针对特殊人群“双录”中存在的问题，银行的整改过程需接受保险公司监督。
五、充分发挥行业组织作用
新疆保险行业协会应当制定辖内人身保险销售行为可回溯管理操作标准、流程要求、质检规范及特殊人群适配措施，并根据市场实际，及时进行修订。
本通知未尽事宜，依照《办法》和《通知》有关要求执行。
