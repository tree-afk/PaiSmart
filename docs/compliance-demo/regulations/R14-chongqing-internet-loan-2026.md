# 重庆金融监管局关于进一步加强辖内银行业金融机构互联网贷款业务风险管理的通知

渝金管规〔2026〕2号
各大型银行重庆市分行、各股份制银行重庆分行、各地方法人银行、各城市商业银行重庆分行、各外资银行重庆分行、各消费金融公司、各村镇银行：
近年来，辖内各银行业金融机构互联网贷款业务持续发展，对促进居民消费发挥了积极作用。但部分机构在相关业务发展中导向存在偏差、管理存在漏洞。为进一步贯彻落实《商业银行互联网贷款管理暂行办法》（银保监会令2020年第9号）、《关于加强商业银行互联网助贷业务管理提升金融服务质效的通知》（金规〔2025〕9号）等制度要求，引导互联网贷款业务更好服务居民合理消费需求、促进互联网贷款业务规范健康发展，结合辖内实际，现提出以下工作要求，请严格遵照执行。
一、切实转变经营导向，坚持审慎经营原则
各银行业金融机构应坚持总行集中管理、权责收益匹配、风险定价合理、业务规模适度的原则，将互联网助贷、联合贷以及通过第三方平台营销获客形成的贷款统一纳入全行风险偏好、资本约束和年度信贷计划。不得将互联网贷款作为弥补线下投放不足、维持短期营收或者扩大客户数量的简单工具。
二、提升自主获客能力，落实机构主体责任
各银行业金融机构应切实履行互联网贷款风险管理主体责任，明确牵头部门和内部责任分工，健全与业务风险状况相适应的治理架构和内控机制，推动业务回归审慎经营本源。同时，进一步减少对互联网平台的路径依赖，健全自主获客、自主风控和贷后管理体系，夯实金融科技、数据治理和人才队伍支撑，实现互联网贷款业务从“流量驱动”向“能力驱动”转变。
三、强化业务风险管理，提升风险识别能力
各银行业金融机构应建立和完善多维数据交叉验证机制，综合考量借款人收入水平、存量负债、外部授信和征信查询等情况，充分识别多头共债和过度负债风险，合理确定授信额度和期限，不得因具有担保、增信措施而放松客户准入资质审批。同时，加强风险模型全生命周期管理，规范模型开发、测试、评审、监测和退出各环节，定期回检优化，防止因模型缺陷导致风险误判。
四、强化合作机构管理，健全准入退出机制
各银行业金融机构应审慎制定准入标准，加强平台运营、增信担保等合作机构准入管理，对合作方担保能力、关联关系进行充分评估，有效实施尽职调查，持续完善合作机构退出机制，支付服务费应当合理定价、质价相符。加强集中度管理，合理设置担保增信类业务规模、融担公司合作业务余额与一级资本金额占比的限额要求。审慎与没有真实消费、经营、交易，主要依靠电话营销、多层转介和外部导流获取客户的中小平台合作。进一步规范平台退出安排，明确合作停止的触发条件、数据返还、客户告知、贷后服务等具体情况，对触及制度安排或触发阈值的合作机构，坚决刚性退出。
五、强化还款资金管理，加强异常监测预警
各银行业金融机构应完善多重信息对账机制，严格开展账务交叉核验、强化资金在途和回款管理，重点防范平台截留、挪用或者滚动调度还款资金，平台运营结构及其他合作方不得以各类账户归集借款人还款资金，防止形成“资金池”。同时，按平台、产品建立还款渠道动态监测机制，对还款渠道占比非正常上升、出现多个收款账户、频繁变更收款主体、延迟划转等情况，应重点关注，及时开展穿透核查。
六、提高贷后管理主动性，强化对合作平台的硬约束
各银行业金融机构应按照最新监管要求及业务可能存在的风险，及时修订与平台机构签署的合作协议。定期开展合作机构催收行为的合规性排查，将合规执行、内控评价、催收行为回溯管理、消费者投诉、信息安全、违规处罚等纳入合作机构考核体系。发现合作机构存在违规催收行为的，应及时纠正；逾期不改正或情节严重的，应采取终止合作等措施。严禁暴力催收、“软暴力”催收等违法违规行为。
七、强化宣传教育引导，切实保护消费者合法权益
各银行业金融机构应严格落实个人贷款综合融资成本明示要求，严格审查合作机构宣传信息并开展定期监测，防止使用诱惑性、误导性语言误导消费者，严禁偷换概念、隐瞒重要风险信息，强化品牌隔离。将消费者权益保护嵌入互联网贷款业务全流程管理体系，畅通业务咨询和投诉受理渠道，设立专职人员处理互联网贷款投诉纠纷，不得直接将投诉纠纷转合作方处理，引导金融消费者有序、合法维权。
八、加强监督检查问责，确保要求落地见效
各银行业金融机构应按照本通知要求，主动开展自查自纠，结合自身管理能力及水平，重新审视业务发展情况，自通知印发之日起三个月内向我局报送专项排查报告。监管部门将通过非现场监管、现场检查等方式强化监督检查，定期通报典型问题；对违反监管要求的，视情节轻重责令限期整改并采取相应监管措施；对整改不力、屡查屡犯的机构及其责任人员，依法依规严肃追责问责，确保各项要求落地见效。
